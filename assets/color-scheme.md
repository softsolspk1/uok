# University of Karachi — Current Site Color Scheme
Extracted from live CSS: https://uok.edu.pk/css/style-original.css

## Brand colors
| Role | Hex | Usage |
|---|---|---|
| Primary Green | `#447e36` | Headings (h1-h5), links, top border, nav highlight, buttons, active states |
| Green (hover/dark variant) | `#4c7941` | Dropdown menu link text |
| Green (dropdown bg variant) | `#467b39` | Dropdown submenu background |
| Light Green (accent) | `#cee5c8` | Icon hover border accents |
| Pale Green-Gray (top bar bg) | `#e0e5ca` | Outer header background band |

## Neutrals
| Role | Hex | Usage |
|---|---|---|
| Nav bar dark | `#444` | Primary navigation bar background |
| Body text | `#555` | Default body copy |
| White | `#fff` | Card/content backgrounds, nav text |
| Light gray bg | `#f7f7f7`, `#f1f1f1`, `#f2f2f2` | Section backgrounds, active tab |
| Border gray | `#d5d5d5`, `#dedede`, `#e1e1e1` | Card/table borders |
| Muted text | `#666`, `#999`, `#818181` | Secondary text, breadcrumbs |
| Dark text | `#333`, `#191919`, `#141414` | Emphasis text, blockquote |

## Typography
- Body font: `Arial, Helvetica, sans-serif`
- Accent/quote font: `Georgia, "Times New Roman", Times, serif`
- Base body size: 11px (legacy small sizing — should be modernized to 16px base for the revamp)

## Logo
- File: `assets/logo.png` (239×66, transparent PNG)
- Wordmark: "UNIVERSITY of Karachi" in green, with the official crescent/star + open-book university crest icon in green.
- Favicon: `assets/favicon.ico`

## Notes for revamp
The current palette is a muted institutional green ("Academic Green") on off-white/cream, with a dark charcoal-gray navigation bar. This is the authentic UoK brand palette and should anchor the new design system (as opposed to the speculative "Heritage Gold #D4AF37" accent proposed in the research blueprint, which does not appear anywhere on the live site — gold can still be considered as a *new* accent addition if desired, but #447e36 green is the one authentic, non-negotiable brand color).
